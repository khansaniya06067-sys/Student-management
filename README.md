# Student Management System

A simple yet effective Python application for managing student records. This project allows users to perform basic database or in-memory operations to handle student information efficiently.

## Features

* **Add Students:** Register new students with their details.
* **View Records:** Display a list of all registered students.
* **Update Information:** Modify existing student details.
* **Delete Records:** Remove student entries when no longer needed.

## Tech Stack

* **Language:** Python
